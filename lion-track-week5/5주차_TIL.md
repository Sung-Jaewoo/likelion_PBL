# 📘 Today I Learned

### 1. 오늘 배운 내용
-기존 HTML/CSS로 만들었던 자기소개 페이지를 React 컴포넌트 구조로 변환하는 작업.
-Vite 기반 React 프로젝트를 생성하고 App.jsx, SummaryCard, DetailCard 등 컴포넌트를 분리하여 구성.
-mock 데이터를 lions.js 파일로 관리하면서 카드 UI가 데이터 기반으로 렌더링.
### 2. 핵심 정리 (내 언어로)
-React = HTML을 그대로 작성하는 방식 x!, UI를 컴포넌트 단위로 나눠서 관리하는 방식 O!
특히 같은 형태의 카드가 반복될 때 직접 HTML을 여러 번 작성하는 것이 아니라, mock 데이터를 배열 형태로 저장한 뒤 map()으로 반복 출력하면 훨씬 효율적!
-외부 API 대신 mock 데이터를 직접 설계해서 사용했는데, 화면에 필요한 정보들을 객체 형태로 정리하고 React 컴포넌트에 전달하는 흐름을 이해할 수 있었음.
CSS도 단순히 적용하는 것이 아니라 React 구조에 맞게 import해야 했고, 이미지 역시 public 폴더 기준 경로를 사용해야 정상적으로 불러와진다는 것을 배우게 되었음.

### 4. 느낀 점
-기존에는 HTML/CSS만으로 화면을 만드는 데 익숙했는데, React로 변환하면서 구조적으로 UI를 관리하는 방식이 훨씬 체계적이라는 것을 느꼈다.
특히 데이터를 기반으로 화면이 자동 생성되는 방식이 신기했고, 컴포넌트 단위로 나누니까 유지보수도 훨씬 편하다는 생각이 들었다.
